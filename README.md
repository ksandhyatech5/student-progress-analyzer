# Student Progress Analyzer

A full-stack web application to track and analyze student performance using:

- Python (FastAPI)
- MongoDB
- Streamlit
- Plotly

## Features
- Add student marks
- View all records
- Calculate average performance
- Visualize progress with charts

## Tech Stack
Backend: FastAPI + MongoDB  
Frontend: Streamlit  

## Run Instructions
1. Install requirements:
   pip install -r requirements.txt

2. Run backend:
   cd backend
   uvicorn main:app --reload

3. Run frontend:
   cd frontend
   streamlit run app.py
